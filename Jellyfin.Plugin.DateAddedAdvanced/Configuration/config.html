Date Added Sources

Choose which file timestamp is used for the Date Added property when scanning items without an existing NFO file.
Applies to movies and TV episodes.
Applies to music albums and songs.

TV Shows

When enabled, episodes inherit their Date Added timestamp from season.nfo or the oldest episode in that season.

NFO File Handling

When enabled, adds the <dateadded> tag to existing NFO files if it is missing. Existing timestamps are always preserved. When disabled, existing NFO files will never be modified.
If an existing NFO file is invalid XML or missing the expected root element, rename it to .bak before creating a clean NFO file.

Metadata Savers (NFO Writers)

Enable writing of .nfo files containing the dateadded timestamp for selected media types.
